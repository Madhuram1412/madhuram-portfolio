## 🌟 Highlights & Features

- **🎬 Welcome Intro Animation**: Developer/AI-themed boot sequence with holographic monogram, real-time loading telemetry, neon progress bar, and seamless reveal transition.
- **⚡ Single Source of Truth**: All information, education milestones, project details, and technical skills strictly align with Madhuram's verified resume.
- **🛠️ Interactive Skills Toolkit**: Categorized into Programming & Web, AI / ML, CS Concepts, and Developer Tools — featuring streaming marquee tickers and project application badges (zero arbitrary percentages).
- **🚀 Featured Project Showcases**:
  - **Vocabo**: Interactive vocabulary learning platform with AI/LLM contextual examples and personalized exercises.
  - **Citizen AI**: AI-powered citizen assistance platform featuring conversational query understanding and contextual retrieval.
- **🎓 Education Timeline**: Modern vertical timeline detailing B.Tech CSE at Mahakal Institute of Technology and schooling at Padmaja Higher Secondary School.
- **🎨 Modern Dark Aesthetic**: Built on a deep obsidian (`#030712`) palette with glassmorphism cards, glowing border beams, and interactive constellation particle background.
- **📱 Fully Responsive**: Fluid layouts optimized for mobile, tablet, laptop, and 4K displays.

## 🛠️ Built With

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [GitHub Pages](https://pages.github.com/) via GitHub Actions CI/CD

## 💻 Local Development Setup

To run this portfolio locally:

```bash
# 1. Clone the repository
git clone https://github.com/Madhuram1412/madhuram-portfolio.git

# 2. Navigate to project directory
cd madhuram-portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Build for production
npm run build
```
